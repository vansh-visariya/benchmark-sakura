What Sakura measures

Accuracy

Pass rate across codegen, bugfix, SQL, refactoring, systems, and protocols. A task counts only when every test passes.

Latency

Time to first token (TTFT) and total generation time per task, streamed from your Ollama instance.

Throughput

Output tokens per second so you can compare quantization, context size, and hardware fairly.

Hardware truth

GPU, CPU, and RAM are probed on the host — not self-reported — so leaderboard entries reflect real setups.

Why this helps the community

Cloud benchmarks and vendor demos often run on hardware most developers never touch. Sakura closes that gap by standardizing tasks and execution while keeping inference on your GPU or CPU.

  • Fair comparisons — Same 23 tasks, same Docker sandbox, same scoring rules for every model.
  • Local-first privacy — Code runs on your machine; only aggregated results are shared if you submit.
  • Small-model focus — Built for 7B/9B/14B-class models on consumer VRAM, not datacenter clusters.
  • Transparent tasks — Every prompt, test, and reference solution lives in the open repo.
  • Contributor-friendly — Add a JSON file, update the manifest, and ship a new task in minutes.

Run the benchmark

Install dependencies, build the sandbox image once, then point Sakura at any Ollama model.

# Clone and install
git clone https://github.com/vansh-visariya/benchmark-sakura.git
cd benchmark-sakura
pip install -e .

# Build the Docker sandbox (one time)
./docker/build.sh   # or: .\docker\build.ps1 on Windows

# List tasks and filter by category or difficulty
sakura list -c systems
sakura list -d hard

# Run benchmark and submit
sakura run --model qwen2.5-coder:7b --submit
sakura run --model deepseek-coder:6.7b --category codegen

# Compare two runs or generate markdown report
sakura compare .results/run_qwen.json .results/run_deepseek.json
sakura report .results/run_qwen.json -o report.md

Results are saved under .results/. Add --submit to POST scores to sakura.vaansh.dev/api/v1/submissions — they appear on the leaderboard within a minute.
