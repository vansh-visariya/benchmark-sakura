Measure what local coding models actually do on your machine

Sakura is a reproducible benchmark for small LLMs running via Ollama on laptops and desktops. It scores real code generation, bug fixes, SQL, and refactors — with sandboxed execution and hardware attestation so results mean something.

What Sakura measures

Accuracy

Pass rate across codegen, bugfix, SQL, and refactor tasks. A task counts only when every test passes.

Latency

Time to first token and total generation time per task, streamed from your Ollama instance.

Throughput

Output tokens per second so you can compare quantization, context size, and hardware fairly.

Hardware truth

GPU, CPU, and RAM are probed on the host — not self-reported — so leaderboard entries reflect real setups.

Why this helps the community

Cloud benchmarks and vendor demos often run on hardware most developers never touch. Sakura closes that gap by standardizing tasks and execution while keeping inference on your GPU or CPU.

  • Fair comparisons — Same 17 tasks, same sandbox, same scoring rules for every model.
  • Local-first privacy — Code runs on your machine; only aggregated results are shared if you submit.
  • Small-model focus — Built for 7B-class models on consumer VRAM, not datacenter clusters.
  • Transparent tasks — Every prompt, test, and reference solution lives in the open repo.
  • Contributor-friendly — Add a JSON file, update the manifest, and ship a new task in minutes.

Task categories

codegen

Code generation

Classic algorithms and utilities — fibonacci, two sum, palindrome, linked lists, JSON parsing.

bugfix

Bug fixing

Off-by-one errors, divide-by-zero, null handling, and regex catastrophic backtracking.

sql

SQL

Joins, aggregates, top-N per group, and recursive hierarchies against in-memory SQLite.

refactor

Refactoring

Extract method, flatten nested logic, and replace conditionals with clearer structure.

Run the benchmark

Install dependencies, build the sandbox image once, then point Sakura at any Ollama model.

# Clone and install
git clone https://github.com/vanshvisariya/benchmark-sakura.git
cd benchmark-sakura
pip install -e .

# Build the Docker sandbox (one time)
./docker/build.sh   # or: .\docker\build.ps1 on Windows

# List tasks and run
sakura list
sakura run --model qwen2.5-coder:7b
sakura run --model deepseek-coder:6.7b --tags codegen --submit

Results are saved under .results/. Use --submit to share scores on this leaderboard when the API is live.
